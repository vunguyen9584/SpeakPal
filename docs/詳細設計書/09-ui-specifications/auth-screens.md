### コンポーネント仕様

| ID        | 要素       | 属性              | バリデーション       |
| --------- | ---------- | ----------------- | -------------------- |
| email     | TextInput  | type: email       | 必須, email format   |
| password  | TextInput  | type: password    | 必須, min: 8         |
| togglePwd | IconButton | icon: eye/eye-off | -                    |
| loginBtn  | Button     | variant: primary  | disabled until valid |
| appleBtn  | Button     | variant: social   | -                    |
| googleBtn | Button     | variant: social   | -                    |

### バリデーションルール

| フィールド | 条件         | エラーメッセージ                          |
| ---------- | ------------ | ----------------------------------------- |
| email      | 必須         | メールアドレスを入力してください          |
| email      | email format | 有効なメールアドレスを入力してください    |
| password   | 必須         | パスワードを入力してください              |
| password   | min: 8       | パスワードは 8 文字以上で入力してください |

### イベント

| イベント         | トリガー          | アクション                     |
| ---------------- | ----------------- | ------------------------------ |
| onEmailChange    | 入力時            | バリデーション実行             |
| onPasswordChange | 入力時            | バリデーション実行             |
| onSubmit         | Log In ボタン押下 | POST /auth/login → Home へ遷移 |
| onAppleLogin     | Apple ボタン押下  | Apple OAuth フロー開始         |
| onGoogleLogin    | Google ボタン押下 | Google OAuth フロー開始        |

### バリデーションルール

| フィールド | 条件                   | エラーメッセージ                 |
| ---------- | ---------------------- | -------------------------------- |
| username   | 必須                   | ユーザー名を入力してください     |
| username   | 3-50 chars             | 3〜50 文字で入力してください     |
| username   | alphanumeric + \_-     | 英数字と\_-のみ使用可能です      |
| email      | 必須                   | メールアドレスを入力してください |
| email      | email format           | 有効なメールアドレスを入力       |
| password   | 必須                   | パスワードを入力してください     |
| password   | min: 8                 | パスワードは 8 文字以上          |
| password   | contains letter+number | 英字と数字を含める必要があります |
| terms      | checked                | 利用規約に同意してください       |
