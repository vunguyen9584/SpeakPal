# 5. 非機能要件

## 5.1. パフォーマンス（Performance）

### 5.1.1. レスポンスタイム

| メトリック                | 要件     | 備考               |
| ------------------------- | -------- | ------------------ |
| ユーザー発話 →AI 応答開始 | < 1000ms | 目標: 800ms        |
| 割り込み検知 →AI 停止     | < 500ms  | 目標: 300ms        |
| 字幕表示遅延              | < 100ms  | リアルタイム性重視 |
| 訂正分析完了              | < 500ms  | AI 応答と同時表示  |
| 提案生成完了              | < 500ms  | AI 応答と同時表示  |

### 5.1.2. スループット

| メトリック         | 要件            |
| ------------------ | --------------- |
| 同時接続ユーザー数 | 1000 CCU        |
| 音声ストリーム帯域 | 16kbps per user |

---

## 5.2. 可用性（Availability）

| 項目             | 要件            | 備考                         |
| ---------------- | --------------- | ---------------------------- |
| アップタイム     | 99.5%           | 月間ダウンタイム約 3.6 時間  |
| 計画メンテナンス | 月 1 回、深夜帯 | ユーザーへの事前通知必須     |
| 障害復旧時間     | < 4 時間        | MTTR (Mean Time To Recovery) |

---

## 5.3. セキュリティ（Security）

### 5.3.1. 認証（Authentication）

| 要件 ID | 要件                                              |
| ------- | ------------------------------------------------- |
| SEC-001 | メールアドレス＋パスワード認証                    |
| SEC-002 | OAuth 2.0（Google/Apple Sign-in）対応             |
| SEC-003 | パスワードは 8 文字以上、英数字混合必須           |
| SEC-004 | セッションタイムアウト：30 日（リメンバーミー時） |

### 5.3.2. 認可（Authorization）

| 要件 ID | 要件                                   |
| ------- | -------------------------------------- |
| SEC-005 | ユーザーは自分のデータのみアクセス可能 |
| SEC-006 | 管理者権限は別途認証が必要             |

### 5.3.3. データ保護

| 要件 ID | 要件                                     |
| ------- | ---------------------------------------- |
| SEC-007 | 通信は TLS 1.3 で暗号化                  |
| SEC-008 | 音声データは処理後即時削除（保存しない） |
| SEC-009 | 会話テキストは暗号化して保存             |
| SEC-010 | 個人情報の第三者提供禁止                 |

---

## 5.4. スケーラビリティ（Scalability）
