# フィードバックシステム (Feedback)

> このファイルはフィードバックに関する機能要件を定義します: FR-004, FR-005, FR-006, FR-017

---

## FR-004: スマート提案表示

### 説明

ユーザーの発話ターン時、または 3 秒以上の沈黙時に、文テンプレートと語彙提案を表示する。

### アクター

- 学習者
- システム

### 事前条件

- 会話セッションが進行中
- ユーザーの発話ターンである

### メインフロー

1. システムがユーザーの発話ターンを検知する
2. 現在の会話コンテキストを分析する
3. 適切なテンプレートを生成する（例：「I prefer [___] because [___]」）
4. 文脈に合った語彙を生成する
5. 提案を UI に表示する
6. ユーザーは提案を参考に発話できる

### 代替フロー

**AF-004-1:** 3 秒以上の沈黙時

1. システムが沈黙を検知する
2. 自動的に提案を表示する

### 例外フロー

**EF-004-1:** 提案生成失敗時

1. 一般的な提案を表示する
2. ログにエラーを記録する

### 事後条件

- 提案が UI 上に表示される

### ビジネスルール

| ルール ID | ルール                                       |
| --------- | -------------------------------------------- |
| BR-008    | 提案はユーザーレベルに応じた難易度で表示する |
| BR-009    | テンプレートには穴埋め形式を使用する         |

### バリデーションルール

| フィールド   | タイプ | 必須 | バリデーション |
| ------------ | ------ | ---- | -------------- |
| テンプレート | String | Yes  | 最大 200 文字  |
| 語彙リスト   | Array  | Yes  | 最大 5 単語    |

## FR-005: ストリーミング字幕

### 説明

AI とユーザーの音声を「カラオケ」形式でリアルタイム表示する。発話に合わせて単語がハイライトされる。

### アクター

- 学習者
- システム

### 事前条件

- 会話セッションが進行中
- 字幕表示がオンになっている

### メインフロー

1. 音声（AI/ユーザー）が検出される
2. リアルタイムでテキストに変換される
3. 発話中の単語がハイライト表示される
4. 完了した単語は通常表示に戻る
5. 一連の発話が完了すると履歴に追加される

### 代替フロー

なし

### 例外フロー

**EF-005-1:** 音声認識遅延時

1. 可能な限り表示を継続する
2. 遅延が著しい場合は一時停止表示する

### 事後条件

- 字幕が画面に表示される
- 会話履歴として保存される

### ビジネスルール

| ルール ID | ルール                               |
| --------- | ------------------------------------ |
| BR-010    | リアルタイム性を最優先する           |
| BR-011    | ハイライトは発話タイミングに同期する |

## FR-006: 即時訂正表示

### 説明

ユーザーの発話終了後、AI が応答すると同時に、発音・文法・語彙エラーを色分けで表示する。

### アクター

- 学習者
- システム

### 事前条件

- ユーザーが発話を完了している
- エラー分析が完了している

### メインフロー

1. ユーザーの発話が終了する
2. システムが並列でエラー分析を実行する
3. AI が音声で応答を開始する
4. **同時に**、ユーザーの発話テキストにエラーマークを表示する
   - 🔴 赤: 発音エラー（Confidence Score 低）
   - 🟡 黄: 文法エラー（正しい形を表示）
   - 🔵 青: より良い語彙の提案
5. ユーザーはエラー詳細をタップして確認できる

### 代替フロー

**AF-006-1:** エラーがない場合

1. エラーマークなしで発話テキストを表示する
2. 「Great job!」などのポジティブフィードバックを表示する

### 例外フロー

**EF-006-1:** 分析タイムアウト時

1. エラーマークなしで表示する
2. 後から分析結果を追加表示する

### 事後条件

- エラー情報が画面に表示される
- エラー履歴が保存される

### ビジネスルール

| ルール ID | ルール                                   |
| --------- | ---------------------------------------- |
| BR-012    | エラー表示は AI 応答と同時に行う         |
| BR-013    | 重大なエラーは赤、軽微なエラーは青で表示 |

### バリデーションルール

| フィールド   | タイプ | 必須 | バリデーション                   |
| ------------ | ------ | ---- | -------------------------------- |
| エラータイプ | Enum   | Yes  | pronunciation/grammar/vocabulary |
| 訂正テキスト | String | Yes  | オリジナルテキストの修正版       |

## FR-017: 語彙解説

### 説明

AI の発話中に含まれる重要な語彙（イディオム、口語表現、難しい単語等）をハイライトし、タップで意味・例文・発音を確認できる機能。

### アクター

- 学習者（登録済みユーザー）
- システム

### 事前条件

- 会話セッションが進行中である
- AI が発話を完了している
- 字幕が表示されている

### メインフロー

1. AI が発話を完了する
2. システムが AI の発話テキストを分析する
3. システムが重要語彙を特定する（ユーザーレベルに応じて）
4. 字幕上で重要語彙をハイライト表示する（下線、異なる色）
5. ユーザーがハイライトされた語彙をタップする
6. システムが語彙解説ポップアップを表示する
   - 意味（日本語訳）
   - 発音記号
   - 例文（2-3 文）
   - 音声再生ボタン
7. ユーザーが音声再生ボタンをタップすると発音が再生される
8. ユーザーがポップアップを閉じる

### 代替フロー

**AF-017-1:** 語彙を単語帳に保存

1. 解説ポップアップで「保存」ボタンをタップする
2. システムが語彙をユーザーの単語帳に保存する
3. 保存成功メッセージを表示する

**AF-017-2:** 履歴画面から語彙確認

1. ユーザーが履歴画面で過去の会話を開く
2. AI 発話内の重要語彙がハイライト表示される
3. タップで解説を確認できる

### 例外フロー

**EF-017-1:** 重要語彙がない場合

1. ハイライト表示なしで字幕を表示する

**EF-017-2:** 解説情報取得失敗時

1. システムが簡易的な意味のみ表示する
2. ログにエラーを記録する

### 事後条件

- 重要語彙がハイライト表示される
- （タップ時）語彙解説が表示される
- （保存時）単語帳に語彙が追加される

### ビジネスルール

| ルール ID | ルール                                                           |
| --------- | ---------------------------------------------------------------- |
| BR-047    | 重要語彙の判定はユーザーレベルに応じて行う                       |
| BR-048    | Beginner は基本単語以外を、Advanced はイディオム・スラングを対象 |
| BR-049    | 1 回の AI 発話で最大 5 語彙までハイライト                        |
| BR-050    | 保存された語彙は単語帳画面で復習可能                             |

### 重要語彙の判定基準

| ユーザーレベル | ハイライト対象                           |
| -------------- | ---------------------------------------- |
| Beginner       | Top1000 語彙以外の全ての単語             |
| Basic          | Top2000 語彙以外、簡単なイディオム       |
| Intermediate   | 難しい単語、イディオム、口語表現         |
| Advanced       | スラング、専門用語、ニュアンスのある表現 |

### 解説ポップアップの表示内容

```
┌─────────────────────────────────┐
│  📖 "hang out"                    │
├─────────────────────────────────┤
│  🔊 /hæŋ aʊt/                       │
│                                   │
│  🌼 意味: 遊ぶ、ぶらぶらする            │
│                                   │
│  📝 例文:                           │
│  ・ I like to hang out with friends │
│  ・ Let's hang out this weekend     │
├─────────────────────────────────┤
│  [ 🔊 発音 ]  [ ⭐ 保存 ]  [ ✖ ]   │
└─────────────────────────────────┘
```
