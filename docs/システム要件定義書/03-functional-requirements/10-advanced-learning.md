# 高度な学習機能 (Advanced Learning)

> このファイルは高度な学習機能に関する機能要件を定義します: FR-030, FR-031, FR-032

---

## FR-030: 発音詳細分析

### 説明

音素レベルで発音を分析し、改善ポイントを視覚的に表示する機能。

### 分析内容

| 項目         | 内容                             |
| ------------ | -------------------------------- |
| 音素スコア   | 各音素の正確性スコア（0-100）    |
| 波形比較     | ネイティブ発音との波形比較       |
| 口の形ガイド | 正しい口の形をアニメーション表示 |
| 練習モード   | 苦手な音素を繰り返し練習         |

### ビジネスルール

| ルール ID | ルール                   |
| --------- | ------------------------ |
| BR-082    | 詳細分析は有料プラン限定 |
| BR-083    | 分析結果は履歴に保存     |

## FR-031: ロールプレイモード

### 説明

実際の状況をシミュレートし、特定の役割を演じて会話練習する機能。

### ロールプレイ例

| シナリオ   | ユーザー役 | AI 役              |
| ---------- | ---------- | ------------------ |
| 就職面接   | 応募者     | 面接官             |
| レストラン | 客         | ウェイター         |
| 病院       | 患者       | 医者               |
| 不動産     | 借主       | 不動産エージェント |

### メインフロー

1. ユーザーがロールプレイシナリオを選択する
2. ブリーフィング画面で状況説明を表示する
3. AI が設定された役割で会話を開始する
4. ユーザーが自分の役割で応答する
5. シナリオ完了後に評価とフィードバックを表示する

### ビジネスルール

| ルール ID | ルール                                   |
| --------- | ---------------------------------------- |
| BR-084    | ロールプレイ完了で 100 XP 獲得           |
| BR-085    | 評価はタスク達成度、流暢さ、正確さで判定 |

## FR-032: TOEIC/IELTS 対策

### 説明

TOEIC Speaking / IELTS Speaking の試験形式に沿った練習モード。

### 対応試験

| 試験           | 練習内容                                                      |
| -------------- | ------------------------------------------------------------- |
| TOEIC Speaking | Q1-2 音読、Q3 写真描写、Q4-6 回答、Q7-9 意見                  |
| IELTS Speaking | Part 1 インタビュー、Part 2 スピーチ、Part 3 ディスカッション |

### 機能詳細

| 機能           | 説明                            |
| -------------- | ------------------------------- |
| 模擬試験       | 本番と同じ時間制限で練習        |
| 問題別練習     | 特定のパートのみ練習            |
| AI 採点        | 発音・流暢さ・語彙・文法で採点  |
| 改善アドバイス | AI による具体的なフィードバック |

### ビジネスルール

| ルール ID | ルール                               |
| --------- | ------------------------------------ |
| BR-086    | TOEIC/IELTS 対策は Pro/Plus 限定     |
| BR-087    | 模擬試験は 1 日 1 回無料、追加は有料 |
| BR-088    | スコア予測は参考値として表示         |
