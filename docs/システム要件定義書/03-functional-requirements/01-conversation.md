# 会話機能 (Conversation)

> このファイルは会話に関する機能要件を定義します: FR-001, FR-002, FR-003, FR-009, FR-010, FR-033

---

## FR-001: 会話モード切替

### 説明

ユーザーが「インストラクターモード」と「フリートークモード」を自由に切り替えられる機能。

### アクター

- 学習者

### 事前条件

- ユーザーがログイン済みである
- 会話セッションが開始されている

### メインフロー

1. ユーザーがモード切替ボタンをタップする
2. システムが現在のモードを確認する
3. システムがモードを切り替える
4. UI が新しいモード状態を反映する
5. AI が新しいモードに適した振る舞いに切り替わる

### 代替フロー

**AF-001-1:** 会話中のモード切替

1. 会話の途中でモード切替が要求される
2. システムが現在の会話コンテキストを保持する
3. 新しいモードで会話を継続する

### 例外フロー

**EF-001-1:** 通信エラー発生時

1. システムがエラーメッセージを表示する
2. 元のモードを維持する
3. ユーザーに再試行を促す

### 事後条件

- モードが正常に切り替わる
- UI が新しいモードを表示する

### ビジネスルール

| ルール ID | ルール                                                            |
| --------- | ----------------------------------------------------------------- |
| BR-001    | Beginner レベルの新規ユーザーはインストラクターモードがデフォルト |
| BR-002    | モード切替は会話中いつでも可能                                    |

## FR-002: インストラクター会話

### 説明

AI が主導して会話を進めるモード。特定のシナリオやトピックに沿って質問を投げかけ、ユーザーの回答を引き出す。

### アクター

- 学習者
- AI ペルソナ

### 事前条件

- インストラクターモードが選択されている
- マイクのアクセス許可がある
- ネットワーク接続が有効

### メインフロー

1. システムがトピック/シナリオを選択する（例：空港で、就職面接）
2. AI が最初の質問を音声で投げかける
3. ユーザーが音声で回答する
4. システムが音声をテキストに変換する
5. AI が回答を分析し、次の質問を生成する
6. AI が音声で応答する
7. 2-6 を繰り返す

### 代替フロー

**AF-002-1:** ユーザーの回答が短すぎる場合

1. AI が追加質問を行う（「なぜ？」「どう感じますか？」）
2. ユーザーからより詳細な回答を引き出す

**AF-002-2:** ユーザーが 3 秒以上沈黙した場合

1. システムが提案を表示する
2. ユーザーは提案を参考に回答できる

### 例外フロー

**EF-002-1:** 音声認識失敗時

1. システムが「もう一度お話しください」と促す
2. ユーザーが再度発話する

**EF-002-2:** AI 応答生成失敗時

1. システムがエラーメッセージを表示する
2. 会話を一時停止し、再接続を試みる

### 事後条件

- 会話履歴が保存される
- フィードバック（訂正情報）が表示される

### ビジネスルール

| ルール ID | ルール                                      |
| --------- | ------------------------------------------- |
| BR-003    | AI はユーザーレベルに応じた語彙・速度で話す |
| BR-004    | Yes/No、A/B 選択質問は Beginner 優先        |
| BR-005    | 沈黙が 3 秒を超えた場合は提案を表示する     |

### バリデーションルール

| フィールド   | タイプ | 必須 | バリデーション                   |
| ------------ | ------ | ---- | -------------------------------- |
| 音声入力     | Audio  | Yes  | 最小 0.5 秒、最大 60 秒          |
| トピック選択 | String | No   | システム定義のトピックリストから |

## FR-003: フリートーク会話

### 説明

ユーザーが自由に会話を開始し、AI が自然に応答するモード。

### アクター

- 学習者
- AI ペルソナ

### 事前条件

- フリートークモードが選択されている
- マイクのアクセス許可がある
- ネットワーク接続が有効

### メインフロー

1. ユーザーが会話を開始する（任意のトピック）
2. システムが音声をテキストに変換する
3. AI がユーザーの発話を理解する
4. AI が自然な応答を生成する
5. AI が音声で応答する
6. 1-5 を繰り返す

### 代替フロー

**AF-003-1:** ユーザーが話題を変えた場合

1. AI が新しいトピックを認識する
2. 自然にトピックを切り替えて会話を続ける

### 例外フロー

**EF-003-1:** 不適切な内容検出時

1. システムが内容をフィルタリングする
2. 適切な応答に誘導する

### 事後条件

- 会話履歴が保存される
- フィードバックが表示される

### ビジネスルール

| ルール ID | ルール                                 |
| --------- | -------------------------------------- |
| BR-006    | AI はユーザーレベルに応じた応答をする  |
| BR-007    | 不適切なコンテンツはフィルタリングする |

## FR-009: 割り込み対応

### 説明

ユーザーが AI の発話中に話し始めた場合、AI は即座に停止して聞く態勢に入る。

### アクター

- 学習者
- AI ペルソナ

### 事前条件

- 会話セッションが進行中
- AI が発話中である

### メインフロー

1. AI が音声で発話中
2. ユーザーが発話を開始する
3. システムがユーザー音声を検知する（<500ms）
4. AI の発話を即座に停止する
5. システムがユーザーの発話を優先して処理する
6. ユーザー発話完了後、AI が応答する

### 代替フロー

なし

### 例外フロー

**EF-009-1:** 誤検知（ノイズ等）の場合

1. システムが短時間の音声を無視する
2. AI の発話を継続する

### 事後条件

- AI が停止し、ユーザーの発話を待つ
- 会話の自然な流れが維持される

### ビジネスルール

| ルール ID | ルール                                 |
| --------- | -------------------------------------- |
| BR-018    | 割り込み検知から停止まで 500ms 以内    |
| BR-019    | 0.3 秒未満の音声は誤検知として無視する |

## FR-010: フィラーワード

### 説明

AI が応答を生成している間、「Um...」「Let me see...」などのつなぎ言葉を挿入して、遅延感を軽減する。

### アクター

- AI ペルソナ

### 事前条件

- AI が応答を生成中
- 生成に時間がかかっている（>300ms）

### メインフロー

1. ユーザーの発話が終了する
2. AI が応答生成を開始する
3. 生成が 300ms を超える場合、フィラーワードを挿入する
4. フィラーワードを音声で再生する
5. 本体の応答が完成次第、続けて再生する

### 代替フロー

**AF-010-1:** 高速応答の場合

1. 生成が 300ms 以内に完了する
2. フィラーワードを挿入せずに直接応答する

### 例外フロー

なし

### 事後条件

- 自然な会話の流れが維持される

### ビジネスルール

| ルール ID | ルール                                       |
| --------- | -------------------------------------------- |
| BR-020    | フィラーワードは多様性を持たせる             |
| BR-021    | 過度に頻繁なフィラーは避ける（連続使用禁止） |

## FR-033: 発話確認モード

### 説明

音声認識結果をユーザーに表示し、送信前に確認・修正できる機能。発音が正確に認識されたかを確認し、誤認識の場合は再発話または手動修正が可能。

### 目的

- 発音が不正確な場合や周囲の雑音による誤認識を防止
- ユーザーが意図した内容が正しく認識されているか確認できる
- 学習者の発音に対する意識向上

### アクター

- 学習者（登録済みユーザー）
- システム

### 事前条件

- ユーザーがログイン済みである
- 会話セッションが進行中である
- 発話確認モードが有効になっている

### メインフロー

1. ユーザーが設定画面で「発話確認モード」をオンにする
2. 会話中、ユーザーが発話する
3. システムが音声をテキストに変換する
4. **AI に送信せず**、認識結果を確認画面に表示する
5. ユーザーが認識結果を確認する
6. ユーザーが以下のいずれかを選択する：
   - ✅ **送信ボタン**: 認識結果が正しければ AI に送信
   - 🔄 **再発話ボタン**: もう一度発話して認識し直す
   - ✏️ **編集ボタン**: テキストを手動で修正
7. （送信を選択した場合）システムが確定したテキストを AI に送信する
8. AI が応答を生成する

### 代替フロー

**AF-033-1:** 手動編集

1. ユーザーが編集ボタンをタップする
2. テキスト入力フィールドが編集可能になる
3. ユーザーがテキストを修正する
4. ユーザーが送信ボタンをタップする
5. 修正されたテキストが AI に送信される

**AF-033-2:** 再発話

1. ユーザーが再発話ボタンをタップする
2. 前回の認識結果がクリアされる
3. システムが再度音声入力を待機する
4. ユーザーが再度発話する
5. 新しい認識結果が表示される

**AF-033-3:** キャンセル

1. ユーザーがキャンセルボタンをタップする
2. 認識結果が破棄される
3. 会話画面に戻る（何も送信しない）

**AF-033-4:** タイムアウト

1. 確認画面で 30 秒以上操作がない場合
2. システムがタイムアウト通知を表示する
3. ユーザーは続行またはキャンセルを選択する

### 例外フロー

**EF-033-1:** 音声認識失敗時

1. システムが「音声を認識できませんでした」と表示する
2. 再発話を促す
3. ユーザーが再度発話する

**EF-033-2:** 空の認識結果

1. 発話が検出されたが認識結果が空の場合
2. システムが「もう少しはっきり話してください」と表示する
3. ユーザーが再度発話する

### 事後条件

- 確認された発話テキストが AI に送信される
- 会話履歴に確認済みの内容が記録される
- （手動修正した場合）オリジナルと修正後の両方が記録される

### ビジネスルール

| ルール ID | ルール                                                  |
| --------- | ------------------------------------------------------- |
| BR-089    | 発話確認モードは設定画面でオン/オフ切り替え可能         |
| BR-090    | デフォルトはオフ（リアルタイム会話を優先）              |
| BR-091    | 確認画面でのタイムアウトは 30 秒                        |
| BR-092    | 手動編集の場合、元の認識結果と修正後の両方を履歴に保存  |
| BR-093    | 発話確認モード中は AI のフィラーワードを挿入しない      |
| BR-094    | Beginner レベルのユーザーには初回利用時にこの機能を推奨 |

### 分析・統計

| 記録項目       | 説明                                 |
| -------------- | ------------------------------------ |
| 確認回数       | 発話確認モードで送信した回数         |

| 手動編集率     | テキストを手動編集した割合           |
