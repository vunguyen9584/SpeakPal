# カスタマイズ (Customization)

> このファイルはカスタマイズに関する機能要件を定義します: FR-007, FR-008

---

## FR-007: AI 速度調整

### 説明

ユーザーが AI の発話速度を 0.75x〜1.25x の範囲でスライダーで調整できる。

### アクター

- 学習者

### 事前条件

- 設定画面にアクセスしている

### メインフロー

1. ユーザーが設定画面を開く
2. 速度スライダーを調整する
3. システムが新しい速度設定を保存する
4. 次の AI 発話から新しい速度が適用される

### 代替フロー

なし

### 例外フロー

**EF-007-1:** 設定保存失敗時

1. エラーメッセージを表示する
2. デフォルト速度を維持する

### 事後条件

- 速度設定が保存される
- AI 発話に速度が適用される

### ビジネスルール

| ルール ID | ルール                                 |
| --------- | -------------------------------------- |
| BR-014    | デフォルト速度はユーザーレベルに基づく |
| BR-015    | 速度は 0.75x〜1.25x の範囲に制限する   |

### レベル別デフォルト速度

| レベル       | デフォルト速度 |
| ------------ | -------------- |
| Beginner     | 0.75x          |
| Basic        | 0.85x          |
| Intermediate | 1.0x           |
| Advanced     | 1.0x - 1.25x   |

## FR-008: カスタムペルソナ作成

### 説明

ユーザーが独自の AI「練習パートナー」を作成できる。名前、声、性格を設定可能。

### アクター

- 学習者

### 事前条件

- ペルソナ作成画面にアクセスしている

### メインフロー

1. ユーザーがペルソナ作成を開始する
2. 名前を入力する
3. 声を選択する（利用可能な声リストから）
4. 性格を選択する（陽気/厳格/皮肉など）
5. 対応レベルを設定する（任意）
6. 保存ボタンをタップする
7. システムがペルソナを保存する

### 代替フロー

**AF-008-1:** 既存ペルソナの編集

1. ペルソナリストから選択する
2. 編集画面で変更する
3. 保存する

### 例外フロー

**EF-008-1:** 名前が重複している場合

1. エラーメッセージを表示する
2. 名前の変更を促す

### 事後条件

- カスタムペルソナが保存される
- 会話でペルソナを選択可能になる

### ビジネスルール

| ルール ID | ルール                                      |
| --------- | ------------------------------------------- |
| BR-016    | ペルソナ名は一意である必要がある            |
| BR-017    | 1 ユーザーあたり最大 5 つのカスタムペルソナ |

### バリデーションルール

| フィールド | タイプ | 必須 | バリデーション                       |
| ---------- | ------ | ---- | ------------------------------------ |
| ペルソナ名 | String | Yes  | 1-20 文字、英数字と空白のみ          |
| 声選択     | Enum   | Yes  | 利用可能な声リストから               |
| 性格       | Enum   | Yes  | cheerful/strict/sarcastic 等         |
| 対応レベル | Enum   | No   | Beginner/Basic/Intermediate/Advanced |

### ペルソナ設定詳細

#### 利用可能な声

| 声 ID    | 名前   | 性別 | アクセント       |
| -------- | ------ | ---- | ---------------- |
| voice_01 | Emma   | 女性 | American English |
| voice_02 | Oliver | 男性 | British English  |
| voice_03 | Sophia | 女性 | Australian       |
| voice_04 | James  | 男性 | American English |
| voice_05 | Mia    | 女性 | British English  |

#### 利用可能な性格

| 性格 ID   | 説明                         |
| --------- | ---------------------------- |
| cheerful  | 陽気で励まし上手             |
| strict    | 厳格で細かいミスも指摘       |
| sarcastic | 皮肉混じりだが親しみやすい   |
| patient   | 忍耐強くゆっくり説明         |
| energetic | エネルギッシュでテンポが良い |
