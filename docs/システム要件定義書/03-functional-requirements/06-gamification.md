# ゲーミフィケーション (Gamification)

> このファイルはゲーミフィケーションに関する機能要件を定義します: FR-018, FR-019, FR-020

---

## FR-018: 学習ストリーク

### 説明

ユーザーの連続学習日数を記録し、ストリーク維持のためのリマインダー通知を送信する機能。

### アクター

- 学習者（登録済みユーザー）
- システム

### 事前条件

- ユーザーがログイン済みである

### メインフロー

1. ユーザーがその日初めて AI 会話を開始する
2. システムが本日の学習をマークする
3. システムがストリークを更新する（連続日数+1 または維持）
4. ホーム画面にストリーク炎アイコンと日数を表示する
5. ストリークマイルストーン（7 日、30 日、100 日等）で祝賀メッセージを表示する

### 代替フロー

**AF-018-1:** ストリークリマインダー

1. 設定された時刻までに学習がない場合
2. システムがプッシュ通知を送信する
3. 「ストリークが途切れそうです！」と表示する

**AF-018-2:** ストリークフリーズ（有料機能）

1. ユーザーがストリークフリーズを使用する
2. 1 日休んでもストリークが維持される
3. フリーズは月に 1 回まで無料、追加は有料

### ビジネスルール

| ルール ID | ルール                                          |
| --------- | ----------------------------------------------- |
| BR-051    | 1 日 1 回以上の AI 会話完了でストリークカウント |
| BR-052    | UTC 00:00 でリセット判定                        |
| BR-053    | ストリークフリーズは月 1 回無料                 |
| BR-054    | ストリーク途切れ時は 0 からリスタート           |

## FR-019: 実績バッジ

### 説明

学習マイルストーン達成時にバッジを獲得できる機能。プロフィールに表示可能。

### バッジカテゴリ

| カテゴリ   | バッジ例                                           |
| ---------- | -------------------------------------------------- |
| ストリーク | 🔥7 日連続、🔥30 日連続、🔥100 日連続              |
| 会話数     | 💬 初会話、💬100 会話、💬1000 会話                 |
| 語彙       | 📚100 語習得、📚500 語習得、📚1000 語習得          |
| レベル     | 🎓Basic 達成、🎓Intermediate 達成、🎓Advanced 達成 |
| 特別       | 🌟 完璧な発音、🌟 深夜の学習者、🎄 季節イベント    |

### メインフロー

1. ユーザーがマイルストーン条件を達成する
2. システムがバッジ獲得判定を行う
3. 祝賀アニメーションとバッジを表示する
4. バッジがプロフィールに追加される
5. XP ボーナスが付与される

### ビジネスルール

| ルール ID | ルール                                     |
| --------- | ------------------------------------------ |
| BR-055    | バッジは一度獲得すると永久保持             |
| BR-056    | 各バッジに XP ボーナスを設定（50〜500 XP） |
| BR-057    | レアバッジはランキングで目立つ表示         |

---

## FR-020: 経験値＆レベル

### 説明

学習アクティビティに応じて XP（経験値）を獲得し、累計 XP でレベルアップする機能。

### XP 獲得ルール

| アクティビティ         | 獲得 XP    |
| ---------------------- | ---------- |
| AI 会話 1 分完了       | 10 XP      |
| デイリーチャレンジ完了 | 50 XP      |
| 新語彙習得             | 5 XP       |
| ストリーク維持         | 20 XP/日   |
| バッジ獲得             | 50〜500 XP |

### レベルテーブル

| レベル | 必要累計 XP | 特典             |
| ------ | ----------- | ---------------- |
| 1-10   | 0-1000      | 基本機能         |
| 11-20  | 1001-3000   | 追加ペルソナ解放 |
| 21-30  | 3001-6000   | 特別シナリオ解放 |
| 31+    | 6001+       | エリートバッジ   |

### ビジネスルール

| ルール ID | ルール                             |
| --------- | ---------------------------------- |
| BR-058    | XP は減少しない（累計制）          |
| BR-059    | レベルアップ時にアニメーション表示 |
| BR-060    | 週間 XP ランキングは別途集計       |
