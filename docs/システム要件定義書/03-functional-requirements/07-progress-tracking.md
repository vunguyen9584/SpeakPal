# 学習進捗トラッキング (Progress Tracking)

> このファイルは学習進捗トラッキングに関する機能要件を定義します: FR-021, FR-022, FR-023

---

## FR-021: 学習統計ダッシュボード

### 説明

ユーザーの学習進捗を可視化するダッシュボード画面。

### 表示項目

| 項目       | 表示内容                      |
| ---------- | ----------------------------- |
| 総学習時間 | 累計/今週/今月の会話時間      |
| 会話回数   | 累計/今週の会話セッション数   |
| 習得語彙   | 単語帳の語彙数、レベル別内訳  |
| 発音スコア | 平均スコア、改善トレンド      |
| ストリーク | 現在の連続日数、最高記録      |
| レベル進捗 | 現在レベル、次レベルまでの XP |

### メインフロー

1. ユーザーがダッシュボード画面を開く
2. システムが学習データを集計する
3. グラフ・チャートで統計を表示する
4. 期間フィルター（週/月/全期間）で切り替え可能

### ビジネスルール

| ルール ID | ルール                    |
| --------- | ------------------------- |
| BR-061    | データは日次バッチで集計  |
| BR-062    | 過去 1 年間のデータを保持 |

---

## FR-022: 発音スコア履歴

### 説明

発音スコアの時系列変化をグラフで表示し、改善を可視化する機能。

### 表示内容

- 日別/週別の平均発音スコア折れ線グラフ
- 音素別スコア（母音/子音/リズム）
- 最も改善した音素ハイライト
- 苦手な音素リスト

### ビジネスルール

| ルール ID | ルール                     |
| --------- | -------------------------- |
| BR-063    | 会話ごとに発音スコアを記録 |
| BR-064    | 90 日間のデータを詳細表示  |

---

## FR-023: 週間/月間レポート

### 説明

定期的に学習レポートをプッシュ通知・メールで送信する機能。

### レポート内容

| 項目         | 内容                         |
| ------------ | ---------------------------- |
| 学習サマリー | 総学習時間、会話数、習得語彙 |
| 進捗比較     | 前週/前月との比較            |
| ハイライト   | 達成バッジ、ベスト発音スコア |
| 次週の目標   | AI 推奨の学習目標            |

### 配信設定

- 週間レポート: 毎週月曜日朝
- 月間レポート: 毎月 1 日朝
- 配信 ON/OFF 設定可能
