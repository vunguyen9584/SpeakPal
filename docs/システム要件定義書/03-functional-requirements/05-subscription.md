# サブスクリプション (Subscription)

> このファイルはサブスクリプションに関する機能要件を定義します: FR-014, FR-015, FR-016

---

## FR-014: サブスクリプション管理

### 説明

ユーザーがサブスクリプションプランを確認・購入・管理できる機能。利用可能なプランは拡張可能な設計。

### プラン一覧

| プラン名 | AI リクエスト/日 | 料金      | 特徴                 |
| -------- | ---------------- | --------- | -------------------- |
| Free     | 3                | 無料      | 基本機能のみ         |
| Plus     | 50               | 月額 x 円 | 全機能利用可能       |
| Pro      | 200              | 月額 y 円 | 全機能＋優先サポート |

> 💡 **拡張性**: 将来的に Ultra 等の新プランを追加可能な設計とする

### アクター

- 学習者（登録済みユーザー）

### 事前条件

- ユーザーがログイン済みである
- インターネット接続が有効である

### メインフロー

1. ユーザーが設定画面から「サブスクリプション」を選択する
2. システムがサブスクリプション画面を表示する
3. システムが現在のプランと利用状況を表示する
4. システムが利用可能なプラン一覧を表示する
5. ユーザーがプランを選択する
6. システムがプラン詳細（機能・料金）を表示する

### 代替フロー

**AF-014-1:** プラン購入

1. ユーザーが「購入」ボタンをタップする
2. システムが App Store/Google Play の決済画面に遷移する
3. ユーザーが決済を完了する
4. システムが購入を検証する
5. システムがプランを有効化する
6. システムが成功メッセージを表示する

**AF-014-2:** サブスクリプションキャンセル

1. ユーザーが「キャンセル」ボタンをタップする
2. システムが確認ダイアログを表示する
3. ユーザーがキャンセルを確認する
4. システムがキャンセルを処理する
5. システムが次回請求日までプランを継続する
6. 次回請求日に Free プランにダウングレードする

### 例外フロー

**EF-014-1:** 決済失敗時

1. システムがエラーメッセージを表示する
2. ユーザーに再試行を促す

**EF-014-2:** 購入検証失敗時

1. システムがリトライ処理を実行する
2. 失敗が続く場合サポートへ連絡を促す

### 事後条件

- 現在のプラン情報が表示される
- （購入時）プランが有効化される
- （キャンセル時）次回請求日までプラン継続

### ビジネスルール

| ルール ID | ルール                                               |
| --------- | ---------------------------------------------------- |
| BR-034    | 新規登録ユーザーは自動的に Free プランが適用される   |
| BR-035    | プランは月額サブスクリプション形式                   |
| BR-036    | App Store/Google Play の In-App Purchase を使用する  |
| BR-037    | キャンセルしても次回請求日までは購入プランを利用可能 |
| BR-038    | プラン情報はデータベースで管理し拡張可能な設計       |

## FR-015: 利用量制限

### 説明

ユーザーのプランに応じて AI 機能の日次リクエスト数を制限する機能。制限に達した場合はアップグレードを促す。

### 利用量制限詳細

| プラン | 会話/日 | 提案/日 | 訂正/日 | リセット時間   |
| ------ | ------- | ------- | ------- | -------------- |
| Free   | 3       | 3       | 3       | 毎日 00:00 UTC |
| Plus   | 50      | 50      | 50      | 毎日 00:00 UTC |
| Pro    | 200     | 200     | 200     | 毎日 00:00 UTC |

### アクター

- 学習者（登録済みユーザー）
- システム

### 事前条件

- ユーザーがログイン済みである
- ユーザーにプランが割り当てられている

### メインフロー

1. ユーザーが AI 機能（会話・提案・訂正）をリクエストする
2. システムがユーザーのプランを確認する
3. システムが本日の利用回数を確認する
4. 利用回数 < 上限 の場合、リクエストを実行する
5. システムが利用回数をインクリメントする
6. システムが残り利用可能回数を UI に表示する

### 代替フロー

**AF-015-1:** 利用制限に達した場合

1. システムが制限到達メッセージを表示する
2. システムがアップグレードボタンを表示する
3. システムがリセットまでの残り時間を表示する
4. ユーザーはアップグレードするか、翌日を待つ

### 例外フロー

なし

### 事後条件

- 利用回数が更新される
- 残り利用可能回数が表示される

### ビジネスルール

| ルール ID | ルール                                               |
| --------- | ---------------------------------------------------- |
| BR-039    | 利用回数は毎日 UTC 00:00 にリセットされる            |
| BR-040    | 制限は AI 機能（会話・提案・訂正）ごとにカウントする |
| BR-041    | 未使用回数は翌日に繰り越さない                       |
| BR-042    | 制限達成後もアプリの他機能（履歴閲覧等）は利用可能   |

### 表示要件

| 表示位置         | 内容                                   |
| ---------------- | -------------------------------------- |
| ホーム画面       | 本日の残り利用可能回数                 |
| 会話画面         | 残り会話回数（上部にさりげなく表示）   |
| 制限達成モーダル | アップグレード提案・リセットまでの時間 |

## FR-016: プラン変更

### 説明

ユーザーがサブスクリプションプランをアップグレードまたはダウングレードできる機能。

### アクター

- 学習者（登録済みユーザー）

### 事前条件

- ユーザーがログイン済みである
- ユーザーにプランが割り当てられている

### メインフロー（アップグレード）

1. ユーザーがサブスクリプション画面で上位プランを選択する
2. システムがプラン比較を表示する
3. ユーザーが「アップグレード」ボタンをタップする
4. システムが料金の差分調整を計算する（日割り計算）
5. システムが App Store/Google Play の決済画面に遷移する
6. ユーザーが決済を完了する
7. システムが新プランを即時有効化する
8. システムが利用制限を新プランの値に更新する

### 代替フロー

**AF-016-1:** ダウングレード

1. ユーザーが下位プランを選択する
2. システムが確認ダイアログを表示する
3. ユーザーがダウングレードを確認する
4. システムが次回請求日から新プラン適用を予約する
5. 現在の請求期間終了までは現プランを継続する

**AF-016-2:** Free プランからのアップグレード

1. 利用制限モーダルからアップグレードを選択する
2. プラン選択画面に遷移する
3. 通常のアップグレードフローに継続する

### 例外フロー

**EF-016-1:** 決済失敗時

1. システムがエラーメッセージを表示する
2. 現在のプランを維持する

**EF-016-2:** サブスクリプション期限切れ時

1. システムが自動的に Free プランにダウングレードする
2. ユーザーに通知を送信する

### 事後条件

- （アップグレード）即時に新プランが有効化される
- （ダウングレード）次回請求日から新プランが適用される
- 利用制限が新プランに応じて更新される

### ビジネスルール

| ルール ID | ルール                                                 |
| --------- | ------------------------------------------------------ |
| BR-043    | アップグレードは即時適用（日割り料金調整）             |
| BR-044    | ダウングレードは次回請求日から適用                     |
| BR-045    | サブスクリプション期限切れは自動的に Free プランに移行 |
| BR-046    | プラン変更時は確認メールを送信する                     |
