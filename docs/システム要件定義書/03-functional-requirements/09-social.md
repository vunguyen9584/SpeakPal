# ソーシャル＆コミュニティ (Social & Community)

> このファイルはソーシャル機能に関する機能要件を定義します: FR-027, FR-028, FR-029

---

## FR-027: 友達招待

### 説明

友達を招待し、招待者・被招待者の両方に報酬を付与するリファラルプログラム。

### 報酬

| 条件               | 招待者報酬                       | 被招待者報酬 |
| ------------------ | -------------------------------- | ------------ |
| 登録完了           | 100 XP                           | 50 XP        |
| 7 日ストリーク達成 | 500 XP + ストリークフリーズ 1 回 | 200 XP       |
| 有料プラン登録     | 1 ヶ月無料延長                   | 初月 50%OFF  |

### メインフロー

1. ユーザーが招待リンク/コードを生成する
2. SNS/メッセージで友達に共有する
3. 友達がリンクからアプリをインストールする
4. 友達が登録時に招待コードを入力する
5. 両者に報酬が付与される

### ビジネスルール

| ルール ID | ルール                   |
| --------- | ------------------------ |
| BR-074    | 1 ユーザーの招待上限なし |
| BR-075    | 自己招待は無効           |
| BR-076    | 報酬は条件達成後即時付与 |

## FR-028: 週間ランキング

### 説明

週間 XP 獲得量でユーザーをランキングし、上位者に報酬を付与する機能。

### ランキング構成

| リーグ       | 参加者数 | 昇格/降格                     |
| ------------ | -------- | ----------------------------- |
| ブロンズ     | 30 人    | 上位 10 名昇格                |
| シルバー     | 30 人    | 上位 10 名昇格、下位 5 名降格 |
| ゴールド     | 30 人    | 上位 10 名昇格、下位 5 名降格 |
| ダイヤモンド | 30 人    | 下位 5 名降格                 |

### 報酬

| 順位    | 報酬                    |
| ------- | ----------------------- |
| 1 位    | 500 XP + ゴールドバッジ |
| 2-3 位  | 300 XP + シルバーバッジ |
| 4-10 位 | 100 XP                  |

### ビジネスルール

| ルール ID | ルール                              |
| --------- | ----------------------------------- |
| BR-077    | 週間リーグは月曜 UTC 00:00 リセット |
| BR-078    | 0 XP の場合はランキング除外         |
| BR-079    | 匿名表示オプションあり              |

## FR-029: グループ学習

### 説明

友達とグループを作成し、グループ内でチャレンジやランキングを共有する機能。

### 機能詳細

| 機能               | 説明                                 |
| ------------------ | ------------------------------------ |
| グループ作成       | 最大 10 人のグループを作成           |
| グループチャレンジ | グループで協力して目標達成           |
| グループランキング | グループ内での XP ランキング         |
| チャット           | グループ内メッセージ（テキストのみ） |

### ビジネスルール

| ルール ID | ルール                                 |
| --------- | -------------------------------------- |
| BR-080    | 1 ユーザー最大 3 グループまで参加可能  |
| BR-081    | グループチャレンジ達成で全員にボーナス |
