# 構造化学習 (Structured Learning)

> このファイルは構造化学習に関する機能要件を定義します: FR-024, FR-025, FR-026

---

## FR-024: シナリオライブラリ

### 説明

状況別の会話シナリオを選択して練習できる機能。

### シナリオカテゴリ

| カテゴリ | シナリオ例                           |
| -------- | ------------------------------------ |
| 旅行     | 空港チェックイン、ホテル予約、道案内 |
| ビジネス | 自己紹介、会議、プレゼン、商談       |
| 日常     | ショッピング、レストラン、電話       |
| 社交     | パーティー、デート、友達作り         |
| 緊急     | 病院、警察、トラブル対応             |

### メインフロー

1. ユーザーがシナリオライブラリ画面を開く
2. カテゴリを選択する
3. シナリオを選択する
4. 難易度を選択する（Beginner/Intermediate/Advanced）
5. AI がそのシナリオのロールを演じる
6. シナリオ完了後に評価とフィードバックを表示する

### ビジネスルール

| ルール ID | ルール                         |
| --------- | ------------------------------ |
| BR-065    | 無料プランは 5 シナリオまで    |
| BR-066    | 有料プランは全シナリオ利用可能 |
| BR-067    | シナリオ完了で XP 獲得         |

## FR-025: デイリーチャレンジ

### 説明

毎日更新される学習ミッションを完了して XP とボーナスを獲得する機能。

### チャレンジ例

| 難易度 | チャレンジ例                 | 報酬            |
| ------ | ---------------------------- | --------------- |
| Easy   | 5 分間会話する               | 30 XP           |
| Medium | 新しい語彙を 3 つ習得する    | 50 XP           |
| Hard   | 発音スコア 80%以上で会話完了 | 100 XP          |
| Bonus  | 全チャレンジ完了             | +50 XP ボーナス |

### メインフロー

1. 毎日 UTC 00:00 に新しいチャレンジが生成される
2. ホーム画面にデイリーチャレンジカードを表示する
3. ユーザーがチャレンジ条件を達成する
4. 達成時に即座に XP が付与される
5. 全チャレンジ完了でボーナス XP を付与する

### ビジネスルール

| ルール ID | ルール                                  |
| --------- | --------------------------------------- |
| BR-068    | チャレンジは毎日 3 つ固定               |
| BR-069    | 未完了チャレンジは翌日リセット          |
| BR-070    | 連続完了でボーナス倍率増加（最大 2 倍） |

## FR-026: 単語帳＆復習

### 説明

保存した語彙を Spaced Repetition System（SRS）で復習できる機能。

### 機能詳細

| 機能         | 説明                                     |
| ------------ | ---------------------------------------- |
| 単語カード   | 語彙・意味・例文・発音のフラッシュカード |
| SRS 復習     | 記憶度に応じて復習間隔を自動調整         |
| クイズモード | 意味選択、スペル入力、発音テスト         |
| 進捗表示     | 未学習/学習中/習得済みの分類             |

### SRS アルゴリズム

| 回答   | 次回復習間隔              |
| ------ | ------------------------- |
| 完璧   | 現在の 2 倍（最大 90 日） |
| 正解   | 現在の 1.5 倍             |
| 難しい | 現在維持                  |
| 不正解 | 1 日にリセット            |

### ビジネスルール

| ルール ID | ルール                        |
| --------- | ----------------------------- |
| BR-071    | 単語は無制限に保存可能        |
| BR-072    | 復習完了で XP 獲得（5 XP/語） |
| BR-073    | 毎日の復習推奨通知を送信      |
