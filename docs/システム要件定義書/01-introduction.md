# 1. はじめに

## 1.1. ドキュメントの目的

本ドキュメントは、SpeakPal AI（AI 英会話練習アプリケーション）のシステム要件定義書（SRS: System Requirements Specification）です。

本書の目的：

- システムの機能要件と非機能要件を明確に定義する
- 開発チーム、テストチーム、ステークホルダー間の共通理解を確立する
- 設計・開発・テストの基準書として使用する
- プロジェクトの範囲と制約を明確にする

---

## 1.2. システムの範囲

### 1.2.1. 対象範囲（In Scope）

| カテゴリ       | 内容                                                                     |
| -------------- | ------------------------------------------------------------------------ |
| 会話機能       | AI とのリアルタイム音声会話（インストラクターモード/フリートークモード） |
| フィードバック | 発音・文法・語彙のリアルタイム訂正表示                                   |
| 提案システム   | 文テンプレート＋文脈に応じた語彙提案                                     |
| ユーザーレベル | 4 段階レベル（Beginner/Basic/Intermediate/Advanced）対応                 |
| カスタマイズ   | AI 速度調整、カスタムペルソナ作成                                        |
| UI/UX          | ビジュアライザー、ストリーミング字幕、訂正バブル表示                     |

### 1.2.2. 対象外（Out of Scope）

| カテゴリ       | 内容                                     |
| -------------- | ---------------------------------------- |
| 他言語対応     | 英語以外の言語学習（日本語、中国語など） |
| 教材管理       | 教材コンテンツの作成・管理システム       |
| 決済システム   | サブスクリプション、課金処理             |
| SNS 連携       | ソーシャルメディアとの連携機能           |
| オフライン機能 | インターネット接続なしでの会話機能       |

---

## 1.3. 用語定義

| 用語                   | 定義                                                   |
| ---------------------- | ------------------------------------------------------ |
| STT                    | Speech-to-Text。音声をテキストに変換する技術           |
| TTS                    | Text-to-Speech。テキストを音声に変換する技術           |
| LLM                    | Large Language Model。大規模言語モデル                 |
| CCU                    | Concurrent Users。同時接続ユーザー数                   |
| WebSocket              | 双方向リアルタイム通信を実現するプロトコル             |
| ペルソナ               | AI の性格・特徴を定義したキャラクター設定              |
| インストラクターモード | AI が主導して会話を進めるモード                        |
| フリートークモード     | ユーザーが自由に会話を始めるモード                     |
| ストリーミング字幕     | 音声の認識・生成に合わせてリアルタイムで表示される字幕 |
| 訂正バブル             | エラー訂正情報を表示する吹き出し UI                    |
| フィラーワード         | 「Um...」「Let me see...」など、考え中を示す言葉       |

## 1.5. ドキュメント概要
