## 4.3. ソフトウェアインターフェース

### 4.3.1. 外部サービス連携

| サービス      | 用途           | プロトコル | 認証方式     |
| ------------- | -------------- | ---------- | ------------ |
| Deepgram      | Speech-to-Text | WebSocket  | API Key      |
| OpenAI GPT-4o | 会話生成＆分析 | WebSocket  | Bearer Token |
| ElevenLabs    | Text-to-Speech | HTTPS      | API Key      |

### 4.3.2. 並列処理パイプライン

```mermaid
sequenceDiagram
    User->>App: 音声発話
    App->>Server: 音声ストリーム
    Server->>STT: 音声送信
    STT-->>Server: テキスト
    par 並列処理
        Server->>LLM: 会話応答生成
        Server->>LLM: エラー分析
        Server->>LLM: 提案生成
    end
    Server->>TTS: 応答テキスト
    TTS-->>Server: 音声ストリーム
    Server-->>App: 音声+エラー+提案
```

## 4.4. 通信インターフェース

### 4.4.1. プロトコル

| プロトコル | 用途                            | ポート |
| ---------- | ------------------------------- | ------ |
| WebSocket  | 双方向リアルタイム音声/テキスト | 443    |
| HTTPS      | REST API 呼び出し               | 443    |

### 4.4.2. 遅延要件

| 処理                      | 最大遅延 | 目標遅延 |
| ------------------------- | -------- | -------- |
| ユーザー発話 →AI 応答開始 | 1000ms   | 800ms    |
| 割り込み検知 →AI 停止     | 500ms    | 300ms    |
| テキスト → 字幕表示       | 100ms    | 50ms     |
