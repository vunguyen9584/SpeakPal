## 概要

SpeakPal AI は、AI を活用した英会話練習アプリケーションです。「本物の人間のような」体験を提供することを目指し、超低遅延、豊かな感情表現、教育的フィードバック（エラー訂正・提案）、学習者レベルに応じた深いパーソナライゼーションを実現します。

主な特徴：

- リアルタイム音声会話と AI による即座のフィードバック
- ユーザーレベル（Beginner〜Advanced）に応じた AI 行動の自動調整
- 発音・文法・語彙のリアルタイム訂正表示
- スマート提案システム（テンプレート＋語彙提案）

## AI コンテキスト情報

### アクター/ユーザー

| アクター       | 説明                                         |
| -------------- | -------------------------------------------- |
| 学習者         | 英会話を練習したいユーザー（4 レベルに分類） |
| AI ペルソナ    | 会話相手となる AI キャラクター               |
| システム管理者 | システムの運用・保守を担当                   |

### コア機能

1. **会話モード** - インストラクターモード / フリートークモード
2. **スマート提案システム** - テンプレート＋語彙提案
3. **リアルタイム表示＆フィードバック** - ストリーミング字幕、即時訂正
4. **カスタマイズ設定** - AI 速度調整、カスタムペルソナ作成

### 主要制約

| 制約タイプ     | 内容                                                     |
| -------------- | -------------------------------------------------------- |
| パフォーマンス | 音声応答遅延 < 1000ms（目標 800ms）                      |
| プロトコル     | WebSocket による双方向音声・テキストストリーミング       |
| 技術スタック   | STT: Deepgram/Whisper, LLM: GPT-4o/Groq, TTS: ElevenLabs |
