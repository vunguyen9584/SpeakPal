## 3. 共通コンポーネント

### 3.1. ボタン

| タイプ    | 用途               | スタイル               |
| --------- | ------------------ | ---------------------- |
| Primary   | メインアクション   | 塗りつぶし、Primary 色 |
| Secondary | サブアクション     | アウトライン           |
| Ghost     | 補助アクション     | 透明背景               |
| Icon      | アイコンのみボタン | 円形                   |
| Mic       | マイクボタン       | 大きな円形、パルス効果 |

### 3.2. 入力フィールド

| タイプ   | 用途           | バリデーション表示     |
| -------- | -------------- | ---------------------- |
| Text     | テキスト入力   | 下部にエラーメッセージ |
| Password | パスワード入力 | 表示切替ボタン付き     |
| Select   | 選択式         | ドロップダウン         |
| Slider   | 範囲選択       | 値表示ラベル付き       |

### 3.3. カード

| タイプ      | 用途             | スタイル               |
| ----------- | ---------------- | ---------------------- |
| Standard    | 一般カード       | Surface 背景、角丸 8px |
| Elevated    | 強調カード       | シャドウ付き           |
| Interactive | タップ可能カード | ホバー/タップ効果      |
| Correction  | 訂正バブル       | 色分け枠線             |
