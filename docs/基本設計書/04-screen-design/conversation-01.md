```
┌─────────────────────────────────────────┐
│  ← 戻る    インストラクター    ⚙️ 設定  │

│  "What do you like to do on weekends?"  │

│        (現在発話中ハイライト)            │
│                                         │

│                                         │
│           ◉◉◉◉◉◉◉◉◉◉◉◉◉               │
```

### 項目定義

| No  | 項目 ID        | 項目名           | 型     | 説明                          |
| --- | -------------- | ---------------- | ------ | ----------------------------- |
| 1   | lbl_mode       | モード表示       | label  | インストラクター/フリートーク |
| 2   | txt_subtitle   | 字幕エリア       | text   | ストリーミング字幕            |
| 3   | viz_audio      | 音声波形         | canvas | オーディオビジュアライザー    |
| 4   | bbl_correction | 訂正バブル       | bubble | エラー訂正表示                |
| 5   | txt_suggestion | 提案テンプレート | text   | 文テンプレート                |
| 6   | lst_vocabulary | 語彙リスト       | list   | 語彙提案ボタン群              |
| 7   | btn_mic        | マイクボタン     | button | 音声入力開始/停止             |
| 8   | btn_end        | 終了ボタン       | button | 会話終了                      |
| 9   | btn_settings   | 設定ボタン       | button | 設定画面へ                    |

### イベント定義

| No  | イベント ID    | トリガー             | アクション                  |
| --- | -------------- | -------------------- | --------------------------- |
| 1   | evt_mic_start  | マイクボタンタップ   | 音声入力開始                |
| 2   | evt_mic_stop   | マイクボタン再タップ | 音声入力停止                |
| 3   | evt_end        | 終了ボタンタップ     | 会話サマリー表示 → ホームへ |
| 4   | evt_correction | 訂正バブルタップ     | 詳細ポップアップ表示        |
| 5   | evt_vocab      | 語彙ボタンタップ     | 語彙詳細/テンプレート挿入   |
| 6   | evt_interrupt  | ユーザー発話開始     | AI 音声停止                 |
