## 📦 モジュールサマリー

| モジュール       | 説明                   | 主要機能                                 |
| ---------------- | ---------------------- | ---------------------------------------- |
| **Auth Module**  | 認証・認可管理         | 登録、ログイン、OAuth、JWT 管理          |
| **User Module**  | ユーザー管理           | プロフィール、設定、レベル管理           |
| **Conversation** | 会話エンジン           | リアルタイム会話、STT/TTS 連携、AI 応答  |
| **Feedback**     | フィードバック処理     | 即時訂正、スマート提案、発音評価         |
| **Persona**      | ペルソナ管理           | カスタムペルソナ作成・管理               |
| **Learning**     | 学習コンテンツ管理     | シナリオ、チャレンジ、語彙管理           |
| **Gamification** | ゲーミフィケーション   | ストリーク、バッジ、XP、ランキング       |
| **Subscription** | サブスクリプション管理 | プラン管理、利用量制限、課金連携         |
| **Progress**     | 進捗管理               | 統計ダッシュボード、レポート             |
| **Social**       | ソーシャル機能         | 招待、グループ、ランキング               |
| **Notification** | 通知管理               | プッシュ通知、メール、リマインダー       |
| **Batch**        | バッチ処理             | 日次/週次/月次ジョブ                     |
| **Translation**  | 翻訳練習               | ダイレクト翻訳、意図翻訳、シャドーイング |
