# フィードバック機能 - ユースケース詳細

## UC-004: スマート提案表示

### 基本情報

| 項目     | 内容                   |
| -------- | ---------------------- |
| UC ID    | UC-004                 |
| UC 名    | スマート提案表示       |
| アクター | AI, System             |
| 前提条件 | 会話中                 |
| 事後条件 | 提案が UI に表示される |
| 関連 FR  | FR-004                 |
| 優先度   | Must                   |

### 基本フロー

1. 学習者が発話終了
2. システムが並列で LLM に提案生成を依頼
3. LLM がテンプレート提案と語彙提案を生成
4. システムが画面下部に提案を表示
5. 学習者が提案をタップで使用（オプション）

### シーケンス図

```mermaid
sequenceDiagram
    participant User as 学習者
    participant App as アプリ
    participant LLM as LLM Service

    User->>App: 発話終了
    App->>LLM: generateSuggestions(context, level)
    LLM-->>App: {template, vocabulary[]}
    App-->>User: 提案UI表示

    alt 提案使用
        User->>App: 提案タップ
        App-->>User: テンプレート挿入
    end
```

### ビジネスルール

| ルール ID | ルール内容                                          |
| --------- | --------------------------------------------------- |
| BR-008    | 提案はユーザーレベルに応じた難易度で生成            |
| BR-009    | テンプレートは「I usually [___] because [___]」形式 |

## UC-005: ストリーミング字幕

### 基本情報

| 項目     | 内容                           |
| -------- | ------------------------------ |
| UC ID    | UC-005                         |
| UC 名    | ストリーミング字幕             |
| アクター | System                         |
| 前提条件 | 会話中                         |
| 事後条件 | リアルタイムで字幕が表示される |
| 関連 FR  | FR-005                         |
| 優先度   | Must                           |

### 基本フロー

1. AI 音声ストリームが再生開始
2. システムがテキストを単語単位で字幕に反映
3. 現在再生中の単語をハイライト（カラオケ式）
4. 音声再生に同期して次の単語へハイライト移動
5. 再生完了で字幕表示完了

### ビジネスルール

| ルール ID | ルール内容                             |
| --------- | -------------------------------------- |
| BR-010    | 字幕表示は音声再生から 50ms 以内の遅延 |
| BR-011    | ハイライトは音声タイミングと同期       |

## UC-006: 即時訂正表示

### 基本情報

| 項目     | 内容                   |
| -------- | ---------------------- |
| UC ID    | UC-006                 |
| UC 名    | 即時訂正表示           |
| アクター | AI, System             |
| 前提条件 | 学習者が発話完了       |
| 事後条件 | 訂正バブルが表示される |
| 関連 FR  | FR-006                 |
| 優先度   | Must                   |

### 基本フロー

1. 学習者が発話終了
2. システムが並列で LLM にエラー分析を依頼
3. LLM が発音・文法・語彙エラーを検出
4. システムが訂正バブルを表示（色分け）
   - 🔴 赤: 発音エラー
   - 🟡 黄: 文法エラー
   - 🔵 青: 語彙提案
5. 学習者がバブルをタップで詳細表示

### シーケンス図

```mermaid
sequenceDiagram
    participant User as 学習者
    participant App as アプリ
    participant LLM as LLM Service

    User->>App: 発話終了
    App->>LLM: analyzeErrors(text, level)
    LLM-->>App: {corrections[]}

    loop 各訂正
        App-->>User: 訂正バブル表示
    end

    alt 詳細確認
        User->>App: バブルタップ
        App-->>User: 訂正詳細ポップアップ
    end
```

### ビジネスルール

| ルール ID | ルール内容                           |
| --------- | ------------------------------------ |
| BR-012    | 訂正表示は AI 応答と同時（並列処理） |
| BR-013    | エラー種別ごとに色分け表示           |

## UC-017: 語彙解説

### 基本情報

| 項目     | 内容                                |
| -------- | ----------------------------------- |
| UC ID    | UC-017                              |
| UC 名    | 語彙解説                            |
| アクター | 学習者                              |
| 前提条件 | 会話中、AI 発話にハイライト語彙あり |
| 事後条件 | 語彙解説が表示される                |
| 関連 FR  | FR-017                              |
| 優先度   | Should                              |

### 基本フロー

1. AI 発話中、重要語彙がハイライト表示
2. 学習者がハイライト語彙をタップ
3. システムが語彙解説ポップアップを表示
   - 意味（日本語訳）
   - 発音記号
   - 例文
   - 類義語
4. 学習者が「保存」をタップで単語帳に追加

### ビジネスルール

| ルール ID | ルール内容                                 |
| --------- | ------------------------------------------ |
| BR-047    | ハイライト語彙はユーザーレベルより上の語彙 |
| BR-048    | 1 発話あたり最大 3 語彙までハイライト      |
| BR-049    | 解説は日本語（UI デフォルト言語）で表示    |
| BR-050    | 保存した語彙は単語帳に追加される           |

## DFD レベル 2: フィードバックモジュール

### データフローダイアグラム

```mermaid
flowchart TB
    subgraph External["外部"]
        User["👤 学習者"]
        LLM["🧠 LLM Service"]
    end

    subgraph FeedbackModule["フィードバックモジュール"]
        P3_1["3.1<br/>エラー分析"]
        P3_2["3.2<br/>提案生成"]
        P3_3["3.3<br/>字幕同期"]
        P3_4["3.4<br/>語彙抽出"]

        D3_1[("訂正<br/>履歴")]
        D3_2[("語彙<br/>データ")]
    end

    User -->|"発話テキスト"| P3_1
    P3_1 -->|"分析依頼"| LLM
    LLM -->|"訂正情報"| P3_1
    P3_1 -->|"訂正バブル"| User
    P3_1 -->|"訂正記録"| D3_1

    User -->|"発話テキスト"| P3_2
    P3_2 -->|"提案依頼"| LLM
    LLM -->|"提案内容"| P3_2
    P3_2 -->|"提案表示"| User

    P3_3 -->|"字幕表示"| User

    P3_4 -->|"語彙抽出"| LLM
    LLM -->|"語彙情報"| P3_4
    P3_4 -->|"語彙保存"| D3_2
```

### サブプロセス定義

| プロセス ID | プロセス名 | 入力            | 出力     | 説明                   |
| ----------- | ---------- | --------------- | -------- | ---------------------- |
| 3.1         | エラー分析 | 発話テキスト    | 訂正情報 | エラーを検出・分類     |
| 3.2         | 提案生成   | 発話テキスト    | 提案内容 | テンプレート・語彙提案 |
| 3.3         | 字幕同期   | 音声タイミング  | 字幕表示 | カラオケ式字幕         |
| 3.4         | 語彙抽出   | AI 応答テキスト | 語彙情報 | 重要語彙を抽出・解説   |
