# サブスクリプション - ユースケース詳細

## UC-014: サブスクリプション管理

### 基本情報

| 項目     | 内容                                     |
| -------- | ---------------------------------------- |
| UC ID    | UC-014                                   |
| UC 名    | サブスクリプション管理                   |
| アクター | 学習者                                   |
| 前提条件 | ユーザーはログイン済み                   |
| 事後条件 | サブスクリプション情報が表示・更新される |
| 関連 FR  | FR-014                                   |
| 優先度   | Must                                     |

### 基本フロー

1. 学習者がサブスクリプション画面を開く
2. システムが現在のプランと残り利用量を表示
3. 利用可能なプラン一覧を表示:
   - Free: 0 円/月、3 回/日
   - Plus: 980 円/月、20 回/日
   - Pro: 1,980 円/月、無制限
4. 学習者がプランを選択
5. App Store/Google Play 決済画面へ遷移
6. 決済完了後、プランが有効化

### ビジネスルール

| ルール ID | ルール内容                                        |
| --------- | ------------------------------------------------- |
| BR-034    | デフォルトは Free プラン                          |
| BR-035    | 決済は App Store/Google Play In-App Purchase 経由 |
| BR-036    | Plus/Pro は月額自動更新                           |
| BR-037    | 更新日の 24 時間前にリマインダー通知              |
| BR-038    | 解約は次回更新日まで有効                          |

## UC-015: 利用量制限

### 基本情報

| 項目     | 内容                     |
| -------- | ------------------------ |
| UC ID    | UC-015                   |
| UC 名    | 利用量制限               |
| アクター | System                   |
| 前提条件 | ユーザーが AI 機能を使用 |
| 事後条件 | 利用量がカウントされる   |
| 関連 FR  | FR-015                   |
| 優先度   | Must                     |

### 基本フロー

1. 学習者が会話を開始
2. システムが現在の利用量をチェック
3. 制限内であれば会話を許可
4. 会話終了時に利用量をカウント
5. 制限到達時は警告を表示
6. 制限超過時はアップグレード促進を表示

### ビジネスルール

| ルール ID | ルール内容                                      |
| --------- | ----------------------------------------------- |
| BR-039    | 日次リクエスト上限: Free=3, Plus=20, Pro=無制限 |
| BR-040    | 1 会話セッション = 1 リクエストとしてカウント   |
| BR-041    | リセットは毎日 00:00 UTC に実行                 |
| BR-042    | 制限到達時はプラン内で残り 0 と表示             |

## UC-016: プラン変更

### 基本情報

| 項目     | 内容                                     |
| -------- | ---------------------------------------- |
| UC ID    | UC-016                                   |
| UC 名    | プラン変更                               |
| アクター | 学習者                                   |
| 前提条件 | ユーザーはログイン済み、有料プラン利用中 |
| 事後条件 | プランが変更される                       |
| 関連 FR  | FR-016                                   |
| 優先度   | Must                                     |

### 基本フロー（アップグレード）

1. 学習者がサブスクリプション画面を開く
2. 上位プランを選択
3. App Store/Google Play 決済画面へ遷移
4. 決済完了
5. 即座に新プランが有効化

### 基本フロー（ダウングレード）

1. 学習者がサブスクリプション画面を開く
2. 下位プランを選択
3. 確認ダイアログを表示
4. 「ダウングレード」をタップ
5. 次回更新日から新プランが有効化

### ビジネスルール

| ルール ID | ルール内容                         |
| --------- | ---------------------------------- |
| BR-043    | アップグレードは即時適用           |
| BR-044    | ダウングレードは次回更新日から適用 |
| BR-045    | 日割り計算は行わない               |
| BR-046    | 解約時は次回更新日まで利用可能     |

## DFD レベル 2: サブスクリプションモジュール

### データフローダイアグラム

```mermaid
flowchart TB
    subgraph External["外部"]
        User["👤 学習者"]
        AppStore["💳 App Store/\nGoogle Play"]
    end

    subgraph SubscriptionModule["サブスクリプションモジュール"]
        P_1["S.1<br/>プラン表示"]
        P_2["S.2<br/>決済処理"]
        P_3["S.3<br/>利用量管理"]
        P_4["S.4<br/>制限チェック"]

        D_1[("サブスク<br/>データ")]
        D_2[("利用量<br/>ログ")]
    end

    User -->|"プラン確認"| P_1
    P_1 -->|"プラン読取"| D_1
    P_1 -->|"プラン情報"| User

    User -->|"プラン選択"| P_2
    P_2 -->|"決済リクエスト"| AppStore
    AppStore -->|"決済結果"| P_2
    P_2 -->|"プラン更新"| D_1
    P_2 -->|"結果通知"| User

    User -->|"AI機能使用"| P_4
    P_4 -->|"制限確認"| D_1
    P_4 -->|"利用量確認"| D_2

    alt 制限内
        P_4 -->|"許可"| User
        P_4 -->|"カウント"| P_3
        P_3 -->|"記録"| D_2
    else 制限超過
        P_4 -->|"アップグレード促進"| User
    end
```

### サブプロセス定義

| プロセス ID | プロセス名   | 入力           | 出力       | 説明                   |
| ----------- | ------------ | -------------- | ---------- | ---------------------- |
| S.1         | プラン表示   | ユーザー ID    | プラン情報 | 現在のプラン情報を表示 |
| S.2         | 決済処理     | プラン選択     | 決済結果   | App Store 決済を処理   |
| S.3         | 利用量管理   | 使用イベント   | 利用量ログ | 日次利用量を記録       |
| S.4         | 制限チェック | 使用リクエスト | 許可/拒否  | プラン制限を確認       |
