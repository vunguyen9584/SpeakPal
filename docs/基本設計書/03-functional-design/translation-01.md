## UC-034: ダイレクト翻訳練習

### 基本情報

| 項目     | 内容                                           |
| -------- | ---------------------------------------------- |
| UC ID    | UC-034                                         |
| UC 名    | ダイレクト翻訳練習                             |
| アクター | 学習者、AI                                     |
| 前提条件 | ログイン済み、レベル設定済み、トピック選択済み |
| 事後条件 | 翻訳結果が履歴に保存、XP 付与                  |
| 関連 FR  | FR-034                                         |
| 優先度   | Must                                           |

### 概要

選択したトピックと学習者のレベルに応じて、母国語（日本語/ベトナム語など）の文を表示し、学習者が英語で口頭翻訳する機能。AI が文法、語彙使用、応答速度を基に採点する。

### 基本フロー

1. 学習者がダイレクト翻訳練習画面を開く
2. トピックを選択する（日常会話、ビジネス、旅行など）
3. システムがレベルに応じた難易度の文を選択
4. 過去 7 日間に出題されていない文をランダムに選ぶ
5. 母国語の文を画面に表示する
6. 学習者が「話す」ボタンをタップする
7. タイマーが開始され、応答時間の計測を開始する
8. 学習者が英語で翻訳を口頭で発話する
9. システムが音声認識で発話をテキスト化する
10. AI が採点を実施する:
    - 文法正確性（40%）
    - 語彙の適切さ（30%）
    - 応答速度（30%）
11. 採点結果とフィードバックを表示する
12. 模範解答を表示し、比較できるようにする

## UC-035: 高度意図翻訳練習

### 基本情報

| 項目     | 内容                            |
| -------- | ------------------------------- |
| UC ID    | UC-035                          |
| UC 名    | 高度意図翻訳練習                |
| アクター | 学習者、AI                      |
| 前提条件 | ログイン済み、Intermediate 以上 |
| 事後条件 | 練習結果が履歴に保存、XP 付与   |
| 関連 FR  | FR-035                          |
| 優先度   | Must                            |

### 概要

母国語の文ではなく、伝えたい「意図・状況」を説明し、学習者がその意図を表現する英語フレーズを自由に発話する機能。表現の多様性と適切さを評価する。

### 基本フロー

1. 学習者が高度意図翻訳画面を開く
2. シチュエーションカテゴリを選択する
3. AI が意図・状況の説明を生成して表示する
   - 例:「**友達が落ち込んでいます。励ましの言葉をかけてください**」
4. 学習者が「話す」ボタンをタップする
5. 学習者が意図を表現する英語フレーズを発話する
6. AI が以下の観点で評価する:
   - 意図との一致度（40%）
   - 表現の自然さ（30%）
   - 語彙の適切さ／多様性（30%）
7. 評価結果を表示する
8. 同じ意図を表現する複数の代替フレーズを表示する

### シーケンス図

```mermaid

    participant App as アプリ
    participant API as Backend
    participant AI as AI Engine
    participant STT as STT Service

    App->>API: getIntentQuestion(category, level)
    API->>AI: レベルとカテゴリを送信
    AI-->>API: 意図説明を生成
    API-->>App: 意図説明データ
    App-->>User: 意図・状況の説明を表示

    User->>App: 「話す」ボタンをタップ
    User->>App: 英語で表現を発話
    App->>STT: 音声認識リクエスト
    STT-->>App: テキスト変換結果

    App->>AI: evaluateIntentExpression(intent, userExpression)
    AI->>AI: 意図との一致度を評価
    AI-->>App: 評価結果と代替表現

    App-->>User: スコアと多様な表現例を表示
    App->>API: saveIntentPracticeResult(result)
    API-->>App: 保存完了
```

## UC-036: ワード連想チャレンジ

### 基本情報

| 項目     | 内容                               |
| -------- | ---------------------------------- |
| UC ID    | UC-036                             |
| UC 名    | ワード連想チャレンジ               |
| アクター | 学習者、AI                         |
| 前提条件 | ログイン済み、レベル設定完了       |
| 事後条件 | チャレンジ結果記録、ランキング反映 |
| 関連 FR  | FR-036                             |
| 優先度   | Should                             |

### 概要

AI が提示するキーワードから素早く関連語句や文を連想して発話するチャレンジ。語彙力と瞬発力を同時に鍛える機能。

### 基本フロー

1. 学習者がワード連想チャレンジを開始する
2. AI がキーワードを提示する（例:「Weather」）
3. 制限時間（5 秒）内に関連する単語、フレーズ、または文を発話する
4. AI が関連性を判定し、正解なら次のキーワードへ進む
5. 60 秒間で何問正解できるかを競う
6. チェーン（連続正解）でボーナスポイント獲得
7. 最終スコアとベスト記録を表示する

### シーケンス図

```mermaid
sequenceDiagram
    participant User as 学習者
    participant App as アプリ
    participant API as Backend
    participant AI as AI Engine
    participant STT as STT Service

    User->>App: チャレンジ開始
    App->>API: startWordAssociationChallenge(level)
    API->>AI: generateKeywords(level)
    AI-->>API: キーワードリスト
    API-->>App: チャレンジセッション開始

    loop 制限時間(60秒)内
        App-->>User: キーワード表示
        App->>App: タイマー開始(5秒)

        User->>App: 関連語/文を発話
        App->>STT: 音声認識
        STT-->>App: テキスト

        App->>AI: evaluateAssociation(keyword, response)
        AI-->>App: 正解/不正解

        alt 正解
            App-->>User: ✓ 表示、次のキーワード
        else 不正解
            App-->>User: ✗ 表示、チェーンリセット
        end
    end

    App->>API: saveChallongeResult(score)
    API-->>App: ハイスコア判定結果
    App-->>User: 最終スコア表示
```

## UC-037: 瞬間応答ドリル

### 基本情報

| 項目     | 内容                         |
| -------- | ---------------------------- |
| UC ID    | UC-037                       |
| UC 名    | 瞬間応答ドリル               |
| アクター | 学習者、AI                   |
| 前提条件 | ログイン済み、レベル設定完了 |
| 事後条件 | ドリル結果保存、弱点分析更新 |
| 関連 FR  | FR-037                       |
| 優先度   | Must                         |

### 概要

質問や状況が素早く次々と提示され、学習者が即座に英語で応答するドリル形式の練習。スピーキングの反射神経を鍛える機能。

### 基本フロー

1. 学習者がカテゴリを選択してドリルを開始する
   - カテゴリ例: 日常質問、意見表明、状況対応
2. AI が質問を音声とテキストで提示する
   - 例:「What do you usually have for breakfast?」
3. 学習者は 10 秒以内に即座に英語で応答する
4. AI が応答の完成度と自然さを即時評価する
5. 10 問連続で実施する
6. 終了後に総合スコアと改善点を表示する

## UC-038: シャドーイング練習

### 基本情報

| 項目     | 内容                                      |
| -------- | ----------------------------------------- |
| UC ID    | UC-038                                    |
| UC 名    | シャドーイング練習                        |
| アクター | 学習者、AI                                |
| 前提条件 | ログイン済み、イヤホン/ヘッドホン使用推奨 |
| 事後条件 | 練習結果保存、発音改善トレンド更新        |
| 関連 FR  | FR-038                                    |
| 優先度   | Should                                    |

### 概要

AI が発話する英語をリアルタイムで聞きながら、同時に（または少し遅れて）真似して発話するシャドーイング練習機能。リスニングとスピーキングを同時に鍛える。

### 基本フロー

1. 学習者がシャドーイングするコンテンツを選択する
   - 会話スクリプト、ニュース、スピーチなど
2. 速度を選択する（0.75x / 1.0x / 1.25x）
3. AI がモデル音声を再生開始する
4. 学習者が AI の音声を聞きながら同時に発話する
5. システムが学習者の発話を録音する
6. AI が以下の観点で分析する:
   - 追従タイミング（AI との時間差）
   - 発音の正確性
   - イントネーション・リズム
   - 発話の完成度
7. 詳細フィードバックを表示する
8. 苦手な部分のみをリピート練習できる

### シーケンス図

```mermaid
sequenceDiagram
    participant User as 学習者
    participant App as アプリ
    participant API as Backend
    participant AI as AI Engine
    participant TTS as TTS Service

    App->>API: getShadowingContent(contentId)
    API-->>App: コンテンツデータ（テキスト、音声URL）
    App-->>User: シャドーイングガイド表示

    User->>App: 速度選択＆練習開始
    App->>TTS: 音声生成（指定速度）
    TTS-->>App: モデル音声

    par シャドーイング（並列処理）
        App-->>User: AI音声を継続再生
        User->>App: 同時に発話（録音）
    end

    App->>API: analyzeShadowing(modelAudio, userAudio)
    API->>AI: 発話分析
    AI->>AI: 追従・発音・リズム評価
    AI-->>API: 分析結果
    API-->>App: 詳細フィードバック

    App-->>User: 詳細フィードバック表示
    App->>API: saveShadowingResult(result)
    API-->>App: 保存完了
```
