## 1.2. システムの目的

### 1.2.1. ビジョン

SpeakPal AI は、AI を活用した英会話練習アプリケーションです。「本物の人間のような」体験を提供することを目指し、以下の価値を実現します：

```
┌─────────────────────────────────────────────────────────────────┐
│                    SpeakPal AI のビジョン                        │
├─────────────────────────────────────────────────────────────────┤
│  🎯 超低遅延（<1秒）での自然な会話体験                          │
│  🎭 豊かな感情表現を持つAIペルソナ                              │
│  📚 教育的フィードバック（訂正・提案）                          │
│  🎓 学習者レベルに応じたパーソナライゼーション                  │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2.2. 解決する課題

| 課題 ID | 課題                           | 影響                           | 解決策                      |
| ------- | ------------------------------ | ------------------------------ | --------------------------- |
| P-001   | 人との会話への恐怖心           | 間違いを恐れて積極的に話せない | AI との安全な練習環境を提供 |
| P-002   | 既存アプリの遅い応答速度       | 自然な会話リズムが得られない   | <1 秒の超低遅延応答         |
| P-003   | 機械的な音声                   | 実際の会話練習として不十分     | 感情豊かな TTS 音声         |
| P-004   | 適切な返答がわからない         | 会話が途切れやすい             | スマート提案システム        |
| P-005   | 即時のエラーフィードバック不足 | 間違いに気づかず学習効果が低下 | リアルタイム訂正表示        |

## 1.3. システム範囲

### 1.3.1. Scope In（対象範囲）

| カテゴリ             | 機能                                                                     |
| -------------------- | ------------------------------------------------------------------------ |
| 会話機能             | AI とのリアルタイム音声会話（インストラクターモード/フリートークモード） |
| フィードバック       | 発音・文法・語彙のリアルタイム訂正表示                                   |
| 提案システム         | 文テンプレート＋文脈に応じた語彙提案                                     |
| ユーザーレベル       | 4 段階レベル（Beginner/Basic/Intermediate/Advanced）対応                 |
| カスタマイズ         | AI 速度調整、カスタムペルソナ作成                                        |
| UI/UX                | ビジュアライザー、ストリーミング字幕、訂正バブル表示                     |
| ユーザー管理         | 登録・認証・プロフィール管理                                             |
| サブスクリプション   | プラン管理・利用量制限・課金連携                                         |
| ゲーミフィケーション | ストリーク・バッジ・XP・レベル                                           |
| 学習進捗             | 統計ダッシュボード・レポート                                             |
| 構造化学習           | シナリオ・チャレンジ・単語帳                                             |
| ソーシャル           | 招待・ランキング・グループ                                               |

### 1.3.2. Scope Out（対象外）

| カテゴリ       | 内容                                     | 理由                       |
| -------------- | ---------------------------------------- | -------------------------- |
| 他言語対応     | 英語以外の言語学習（日本語、中国語など） | Phase 2 以降で検討         |
| 教材管理       | 教材コンテンツの作成・管理システム       | 別システムとして構築       |
| 決済システム   | サブスクリプション、課金処理             | App Store/Google Play 委託 |
| SNS 連携       | ソーシャルメディアとの連携機能           | Phase 2 以降で検討         |
| オフライン機能 | インターネット接続なしでの会話機能       | 技術的制約                 |

## 1.4. アクター定義

### 1.4.1. プライマリアクター

| アクター ID | アクター名     | 説明                                 | 技術レベル |
| ----------- | -------------- | ------------------------------------ | ---------- |
| ACT-001     | ゲスト         | 未登録ユーザー（登録・ログインのみ） | 一般       |
| ACT-002     | 学習者         | 登録済みユーザー（全機能利用可能）   | 一般       |
| ACT-003     | AI ペルソナ    | 会話相手となる AI キャラクター       | システム   |
| ACT-004     | システム管理者 | システムの運用・保守を担当           | 技術者     |

### 1.4.2. 学習者レベル定義

システムは 4 段階のユーザーレベルをサポートし、AI の振る舞いを自動調整します：

| レベル           | 学習者の特徴                                   | AI の振る舞い                                                   | デフォルト速度 |
| ---------------- | ---------------------------------------------- | --------------------------------------------------------------- | -------------- |
| **Beginner**     | 語彙が少ない、ためらいがち、単文のみ           | ゆっくり話す、Top500 語彙使用、短文、Yes/No・A/B 選択質問を優先 | 0.75x          |
| **Basic**        | 基本的なコミュニケーション、挨拶・自己紹介可能 | やや遅め、忍耐強く待つ、シンプルな文法                          | 0.85x          |
| **Intermediate** | 馴染みのあるトピックで流暢、議論を始められる   | 自然な速度、関係節・簡単なイディオム使用                        | 1.0x           |
| **Advanced**     | ネイティブレベルのコミュニケーション           | 速い速度、スラング使用、ニュアンスのある表現、抽象的なトピック  | 1.0x - 1.25x   |

## 1.5. 制約条件

### 1.5.1. 技術的制約

| 制約 ID | 制約内容                   | 理由                         | 影響           |
| ------- | -------------------------- | ---------------------------- | -------------- |
| TC-001  | 音声応答遅延 < 1000ms      | 自然な会話体験に必要         | アーキテクチャ |
| TC-002  | WebSocket 必須             | 双方向リアルタイム通信に必要 | プロトコル     |
| TC-003  | 常時インターネット接続必須 | クラウド AI サービス利用     | ユーザー環境   |
| TC-004  | マイク・スピーカー必須     | 音声会話機能に必要           | デバイス要件   |

### 1.5.2. ビジネス制約

| 制約 ID | 制約内容                                        | 対応策               |
| ------- | ----------------------------------------------- | -------------------- |
| BC-001  | 外部 AI サービス（OpenAI, Deepgram 等）への依存 | フォールバック設計   |
| BC-002  | API 利用コスト                                  | 利用量制限・最適化   |
| BC-003  | App Store/Google Play ガイドライン準拠          | ガイドライン定期確認 |

### 1.5.3. 法的制約

| 制約 ID | 制約内容                     | 対応                       |
| ------- | ---------------------------- | -------------------------- |
| LC-001  | 音声データのプライバシー保護 | 音声データは処理後即時削除 |
| LC-002  | 個人情報保護法への準拠       | プライバシーポリシー整備   |
| LC-003  | GDPR 対応（EU 圏ユーザー）   | データ処理同意取得         |

## 1.6. 前提条件

| 前提 ID | 内容                                                     | 確認方法       |
| ------- | -------------------------------------------------------- | -------------- |
| AS-001  | ユーザーは安定したインターネット接続を持つ               | 接続確認画面   |
| AS-002  | ユーザーのデバイスにはマイクとスピーカーが装備されている | 権限確認       |
| AS-003  | ユーザーは英語の基本的な理解がある（完全初心者は対象外） | レベル選択画面 |
| AS-004  | 外部 AI サービスの API は安定して利用可能である          | ヘルスチェック |

## 1.8. 用語集

### 1.8.1. ビジネス用語

| 用語                   | 定義                                                   |
| ---------------------- | ------------------------------------------------------ |
| ペルソナ               | AI の性格・特徴を定義したキャラクター設定              |
| インストラクターモード | AI が主導して会話を進めるモード                        |
| フリートークモード     | ユーザーが自由に会話を始めるモード                     |
| ストリーミング字幕     | 音声の認識・生成に合わせてリアルタイムで表示される字幕 |
| 訂正バブル             | エラー訂正情報を表示する吹き出し UI                    |
| フィラーワード         | 「Um...」「Let me see...」など、考え中を示す言葉       |
| ストリーク             | 連続学習日数                                           |
| SRS                    | Spaced Repetition System（間隔反復学習）               |

### 1.8.2. 技術用語

| 用語      | 定義                                         |
| --------- | -------------------------------------------- |
| STT       | Speech-to-Text。音声をテキストに変換する技術 |
| TTS       | Text-to-Speech。テキストを音声に変換する技術 |
| LLM       | Large Language Model。大規模言語モデル       |
| CCU       | Concurrent Users。同時接続ユーザー数         |
| WebSocket | 双方向リアルタイム通信を実現するプロトコル   |
| XP        | Experience Points（経験値）                  |
| JWT       | JSON Web Token。認証トークン形式             |
